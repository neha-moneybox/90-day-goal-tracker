# First 90 Days: goal tracker

A one-page goal board, read from `goals.json`.

## Update the goals
Edit `goals.json` (on GitHub: open the file, click the pencil, edit, then "Commit changes"). The page shows the change within a minute or two.

- `status`: done, progress, planned or idea
- `area`: delivery, capacity or influence
- `horizon`: 30, 60 or 90
- Change `updated` to today's date.

## Host it on GitHub Pages
1. Create a repository and upload `index.html` and `goals.json` (and this README).
2. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)` → Save.
3. The site appears at `https://<your-username>.github.io/<repo-name>/` after a minute or two.

Note: on a public repository the page is public to anyone with the link.
